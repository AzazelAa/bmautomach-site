# BMAutomach landing page

Static landing page for `bmautomach.com`, positioned as an industrial automation startup.

## Files

- `index.html`: page content and structure.
- `styles.css`: responsive visual design.

## Deploy

This repository is configured for the `bmautomach.com` custom domain through `CNAME`.

## Suggested use

Use this page before applying to startup programs such as Claude for Startups. It presents BMAutomach as a company building industrial automation software, PLC/HMI integrations, smart bench monitoring, real-time dashboards, and AI-assisted reports.
